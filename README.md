Questa repository raccoglie 20 progetti sviluppati durante il corso **JavaScript 20 Projects** di Zero To Mastery. Ogni progetto nasce con un obiettivo ben preciso, ovvero mettere in pratica, attraverso applicazioni complete e funzionanti, i concetti fondamentali di JavaScript e del browser.

Lavorando esclusivamente con **Vanilla JavaScript, HTML5 e CSS3**, ho affrontato progressivamente diversi aspetti: 

* **DOM manipulation** e creazione dinamica degli elementi.

* **Event handling** e gestione delle interazioni dell'utente.

* **Async JavaScript**, `fetch`, `async/await` e API REST.

* **Gestione dello stato** e persistenza dei dati tramite Local Storage.

* **Web API native**, tra cui Canvas, Web Speech, Drag & Drop e Picture-in-Picture.

* **Responsive UI** e interazione tra JavaScript, HTML e CSS.
